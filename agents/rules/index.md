# 规范索引

本目录存放所有适用于 apanel 项目的 AI 协作与编码规范。
适用工具：Claude Code、Codex、Cursor 及其他 AI 编辑器。

## 文件列表

| 文件 | 适用范围 | 核心关注点 |
|------|----------|------------|
| [git.md](./git.md) | 所有子项目 | 提交信息格式、分支命名、PR 规范 |
| [go.md](./go.md) | `api/` 目录 | 包结构、命名、错误处理、测试 |
| [frontend.md](./frontend.md) | `web/` 目录 | 组件结构、样式规范、状态管理 |
| [api.md](./api.md) | 前后端接口边界 | 响应格式、路由设计、错误码 |

## 使用原则

- 规范文件是约束，不是建议——偏离时需在 PR 说明中注明原因
- 跨子系统的联调任务记录在 `joint/`，不在此处
- 功能边界和约束定义记录在 `spec/`，不在此处
