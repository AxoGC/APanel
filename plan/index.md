## 状态说明

| 状态 | 含义 |
|------|------|
| `draft` | 草稿，尚未开始 |
| `active` | 进行中 |
| `blocked` | 被阻塞，等待外部条件 |
| `review` | 实现完成，等待审查 |
| `done` | 已完成并验证 |
